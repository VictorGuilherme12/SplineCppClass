# Realistic Spline System / Sistema de Spline Realista

## English Version

### Description
This repository contains the files and scripts related to developing a realistic spline system, implemented in C++ within Unreal Engine 5. The objective is to create an efficient and customizable spline-based path system compatible with automatic navigation and advanced movement logic.

### Project Objective
- Develop a spline system with realistic behavior and customization options.
- Implement functionalities such as dynamic spline point modification and automatic navigation support.
- Ensure modularity for easy customization of spline paths and movement behaviors.
- Provide smooth integration with other Unreal Engine components.

### Technologies Used
- Unreal Engine 5
- C++
  
### Key Features
- **Spline Component Control**: Comprehensive system using `USplineComponent` for advanced spline path handling.
- **Dynamic Modifications**: Runtime control over spline points for real-time adjustments.
- **Navigation Integration**: Compatibility with automatic navigation along spline paths.
- **Modular Approach**: Easily replaceable components for customized behavior and movement logic.

## Versão em Português

### Descrição
Este repositório contém os arquivos e scripts relacionados ao desenvolvimento de um sistema de spline realista, implementado em C++ na Unreal Engine 5. O objetivo é criar um sistema de trajetos baseado em spline eficiente e personalizável, compatível com navegação automática e lógica de movimento avançada.

### Objetivo do Projeto
- Desenvolver um sistema de spline com comportamento realista e opções de personalização.
- Implementar funcionalidades como modificação dinâmica de pontos da spline e suporte à navegação automática.
- Garantir modularidade para facilitar a personalização de trajetos e comportamentos de movimento.
- Fornecer integração suave com outros componentes da Unreal Engine.

### Tecnologias Utilizadas
- Unreal Engine 5
- C++

### Funcionalidades Principais
- **Controle do Componente Spline**: Sistema completo usando `USplineComponent` para manipulação avançada de trajetos.
- **Modificações Dinâmicas**: Controle dos pontos da spline em tempo de execução para ajustes em tempo real.
- **Integração com Navegação**: Compatibilidade com navegação automática em trajetos spline.
- **Abordagem Modular**: Componentes facilmente substituíveis para comportamentos e trajetos personalizados.
